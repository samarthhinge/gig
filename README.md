# KaamSetu

## How to run in VS Code

1. Unzip this folder and open it in VS Code.
2. Open a terminal in VS Code (Terminal → New Terminal).
3. Install dependencies:
   ```
   npm install
   ```
4. Start the dev server:
   ```
   npm run dev
   ```
5. Open the URL shown in the terminal (usually http://localhost:5173) in your browser.

Requires Node.js installed (v18+ recommended). Download from https://nodejs.org if you don't have it.
